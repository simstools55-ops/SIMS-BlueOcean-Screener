# SIMS Blue Ocean Screener v0.2.0

## 主な変更

- 3語の有望候補から、検索意図を具体化した4語ロングテール候補を自動生成する処理を本フローへ接続しました。
- 生成4語は `GENERATED_4WORD` として、入力CSVに実在する4語 `EXISTING_4WORD` と明確に区別します。
- 生成4語は需要未確認扱いとし、SERP精査でサジェスト・Q&A・実検索等の需要Signalが確認できるまでGREENにしません。
- 1つの3語候補から最大2件、全体で最大20件の4語候補を生成します。
- 4語深掘り対象はPre Score 50〜79の3語候補に限定します。
- XLSXは未実装のため、Drive選択画面ではCSV/TSVだけを入力候補として表示するよう修正しました。
- Code.gs内に残っていた旧v0.1.x表記を除去し、v0.2.0へ統一しました。

## v0.1.12からの差し替え

- Code.gs: 置換
- DrivePicker.html: 変更なし
- appsscript.json: 変更なし

## 実機試験

1. Code.gsを丸ごと置換
2. 保存してスプレッドシートを再読み込み
3. 同じラッコCSVを再度読み込む
4. `2. ブルーオーシャン候補を探索する`
5. 完了ダイアログで「新規4語深掘り候補」の件数を確認
6. Candidatesで Source=`GENERATED_4WORD` の候補が出ることを確認
7. SERP精査Packageを生成し、生成4語もWeb精査へ送る

## 注意

`GENERATED_4WORD` は「AI/ルールで作っただけのキーワード」です。
検索需要があるとは限らないため、入力ファイルに実在するキーワードよりEvidenceを弱く扱い、SERP精査前にGREEN判定しません。
