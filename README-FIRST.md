# SIMS Blue Ocean Screener v0.4.0

## 今回の改善

### 1. 初期「シート1 / Sheet1」の整理
- Googleスプレッドシート作成時の空の初期シートを自動削除します。
- `シート1` / `Sheet1` に実データが入っている場合は削除しません。
- Homeを先頭タブへ配置します。

### 2. Homeを製品ダッシュボード化
Homeを単純な縦表から、SIMS製品として使いやすいダッシュボードへ刷新しました。

表示内容:
- 製品名 / Version
- 対象ブログ
- 入力ファイル
- 現在の処理状態
- 総キーワード数
- 3語候補
- 既存4語
- 生成4語
- SERP精査待ち
- カニバリ精査待ち
- GREEN
- Creator依頼可能
- YELLOW / BLOCK / 類似候補へ統合
- Creator依頼済み
- 1〜8の標準作業フロー

Homeではグリッド線を非表示にし、情報カード型のレイアウトで現在状況を一目で確認できます。

## v0.3.1からの差し替え
- Code.gs: 置換
- DrivePicker.html: 変更なし
- appsscript.json: 変更なし

## 確認手順
1. Code.gsを丸ごと置換
2. 保存してスプレッドシートを再読み込み
3. 空の「シート1 / Sheet1」が消えていることを確認
4. Homeが先頭タブにあり、製品ダッシュボード表示になっていることを確認
5. 既存の候補件数がHomeカードへ反映されていることを確認

## 安全仕様
初期シートと同名でも、セルに実データが存在するシートは自動削除しません。
