# SIMS Blue Ocean Screener v0.3.0

## この版の目的

v0.2.0で実証済みのブルーオーシャン探索フローを維持しながら、利用者UI・誤操作防止・進捗表示・運用導線をまとめて整えたUI/運用完成版です。

## 主な変更

### Drive Picker
- ファイル名クリックだけでは処理を開始しません。
- クリックすると選択行にチェックマーク `✓` と選択背景を表示します。
- `このファイルを選ぶ` を押した時点で初めて処理します。
- ファイル未選択時は決定ボタンを無効化します。
- `閉じる` ボタンを常設します。
- キーワードCSV/TSV、SERP結果JSON、Evidence ZIP、カニバリ結果JSONの全ファイル選択に共通適用します。
- フォルダー移動と保存先フォルダー選択は従来どおり利用できます。

### Candidates
- `PENDING` → `SERP精査待ち`
- `CANNIBAL_PENDING` → `カニバリ精査待ち`
- `CLUSTERED` → `類似候補へ統合`
- Creator依頼文作成済み行をグレーアウトします。
- 既存のv0.2.0データも起動時に表示ラベルへ移行します。

### Home
以下を一画面で確認できるようにしました。
- 総キーワード数
- 3語候補
- 既存4語候補
- 生成4語候補
- SERP精査待ち
- カニバリ精査待ち
- GREEN / YELLOW / BLOCK
- 類似候補へ統合
- Creator依頼可能
- Creator依頼済み
- 現在の処理状態

### 操作案内
主要な完了ダイアログに「次に何をするか」を表示します。

## 今回入れていない将来機能

## 推奨実機確認

1. Code.gs / DrivePicker.htmlを置換
2. スプレッドシートを再読み込み
3. `1. キーワードファイルを読み込む` を開く
4. ファイルを1回クリックしても処理が始まらず、✓が付くことを確認
5. `このファイルを選ぶ` で初めて処理されることを確認
6. `閉じる` で何も処理せず閉じられることを確認
7. Homeの集計欄を確認
8. Candidatesの待ち状態が日本語表示になっていることを確認
